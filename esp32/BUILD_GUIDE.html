Rules that keep it clean

MASTER PIN MAP

  • MIC  SCK → GPIO4  ·  WS → GPIO5  ·  SD → GPIO6
  • MIC  VDD → 3V3  ·  L/R → GND  ·  GND → GND
  • AMP  BCLK → GPIO15  ·  LRC → GPIO16  ·  DIN → GPIO7
  • AMP  VIN → 5V  ·  GND → GND  ·  SD: unconnected
  • I2S0 = mic  ·  I2S1 = speaker  ·  16MB flash  ·  8MB PSRAM
